# 现场课件的页型与上屏检查

按实际上课的顺序组织内容。全套沿用所选样稿的字体层级、色彩和导航，内页按现场用途选择构图。

| 页面 | 展示重点 |
| --- | --- |
| 封面 | 主题与学完能做的事。可搭配一项真实工作产物或实际界面细节。 |
| 概念 | 一项和业务任务有关的判断，用一个案例或一张结构图讲清。 |
| 功能演示 | 入口、材料、操作、结果和核对方法。关键界面与步骤并排，或让输入与输出相邻。 |
| 对照 | 用双栏或分步揭示突出变化。只高亮要观察的原文、字段或结果。 |
| 练习与讲评 | 先给任务、交付物和通过标准。参考答案在讲评页或按需展开。 |

- 真实截图裁到可看清操作和结果，保留辨认入口所需的界面上下文。实测结果、模拟演示和参考答案按实际情况标注。
- 以讲师身份走完材料、操作、结果和核对，再以学员身份走一遍练习。按实际投屏比例检查关键文字和操作目标，条件未知时用 16:9。内容过密时按任务拆页，保住字号和阅读顺序。
- 如果使用自动演示，按讲解节奏实测入场、停止点、翻页和重播。沿用 B 版课堂动效时参见 `training-html-motion` 的实际模板。
