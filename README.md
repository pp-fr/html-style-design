# HTML 文档样式设计 · html-style-design

用于千问办公材料展示的 HTML 文档设计 Skill。它根据读者、文档用途和使用场景选择版式，交付可在浏览器打开的单文件 HTML。

## 可以用在哪

| 场景 | 展示重点 |
| --- | --- |
| 案例申报、工作汇报 | 首屏交代事情、阶段和结果，正文把证据放在对应结论旁边 |
| 培训课件、现场演示 | 按讲课顺序翻页，演示页呈现输入、操作、产出和核对方法 |
| 操作手册、执行方案 | 把步骤、操作入口、完成标志和负责人放在读者找得到的地方 |

## 怎么工作

1. 先判断给谁看、在哪里打开，以及读者第一眼需要看懂什么。
2. 选择同类样稿，做出首屏和一个代表性页面，确认版式后再展开。
3. 有流程、对比或状态变化时，用图、对照或可操作的演示辅助理解。交付前在浏览器核对阅读顺序、目录和实际操作。

## 展示示例

> 把一份已经脱敏的试跑记录做成面向审核员的单文件 HTML。首屏说清业务难点、本人贡献和试跑结果，正文按背景、实施、贡献和结果组织。先给可打开的首屏和代表内页。
